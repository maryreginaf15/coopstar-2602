# 🚀 Coopstar — Refatoração e Modernização do Projeto

Recentemente finalizei a refatoração completa do projeto **Coopstar**

O projeto é uma aplicação voltada para **simulação e gerenciamento de serviços de transporte**, com foco em organização de informações, usabilidade e melhoria da experiência do usuário.

Durante o processo de refatoração, utilizei tecnologias como **HTML, CSS e JavaScript**, aplicando melhorias estruturais e visuais para tornar a aplicação mais moderna, escalável e eficiente.

---

# 🔧 Principais melhorias implementadas

* ✅ Reestruturação do código para uma arquitetura mais limpa e modular
* ✅ Aplicação de boas práticas de desenvolvimento front-end
* ✅ Melhoria na organização dos arquivos e componentes
* ✅ Refatoração de funções para uma lógica mais clara e reutilizável
* ✅ Otimização da manutenção e escalabilidade do projeto
* ✅ Atualização para padrões modernos de desenvolvimento web
* ✅ Melhor experiência visual e navegação mais intuitiva

---

# ▶️ Como executar o projeto localmente

Siga o passo a passo abaixo para rodar o projeto na sua máquina:

## 1️⃣ Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/coopstar.git
```

---

## 2️⃣ Acesse a pasta do projeto

```bash
cd coopstar
```

---

## 3️⃣ Abra o projeto

Você pode abrir o projeto utilizando:

* VS Code
* IntelliJ
* Sublime Text
* Ou qualquer editor de sua preferência

---

## 4️⃣ Execute o projeto

Como o projeto utiliza HTML, CSS e JavaScript puro, basta abrir o arquivo:

```bash
index.html
```

Ou utilizar a extensão **Live Server** no VS Code para melhor experiência.

---

# ⚡ Executando com Live Server (Recomendado)

## Instale a extensão:

* Live Server — VS Code Extension

## Depois:

1. Clique com o botão direito no arquivo `index.html`
2. Selecione:

```bash
Open with Live Server
```

O projeto será iniciado automaticamente no navegador.
